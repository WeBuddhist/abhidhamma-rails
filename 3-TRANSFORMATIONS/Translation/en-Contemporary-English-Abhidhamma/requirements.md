# Translation requirements — en-Contemporary-English-Abhidhamma

## Purpose

A contemporary English rendering of the Pāḷi Abhidhamma Piṭaka, aligned to the CSCD/tipitaka.org Mūla edition. Accessible to educated English readers with an interest in Buddhist philosophy; does not require prior Pāḷi knowledge. Follows the literal, formulaic structure of the source closely without becoming archaic.

## Register

- Contemporary academic English; no Elizabethan forms (no "hath", "thereof", "herein" etc.)
- Technical Abhidhamma vocabulary is preferred over paraphrase where an established English equivalent exists
- Repetitive formulaic structures (the triplet and dyad enumeration patterns) must be rendered with consistent parallel phrasing throughout

## Key term directives

### dhammā / dhamma
- **In Abhidhamma enumeration context** (triplets, dyads, grouped phenomena): render as **states** — e.g. "Wholesome states. Unwholesome states. Indeterminate states."
- **In philosophical/relational context** (as object, path, root, predominant condition): render as **phenomena** — e.g. "Phenomena that have the path as object."
- When dhamma refers to the Buddha's Teaching (capitalised context): render as **Dhamma** (transliteration).

### Primary term mappings
- kusalā / kusalaṃ → **wholesome**
- akusalā / akusalaṃ → **unwholesome**
- abyākatā / abyākataṃ → **indeterminate**
- cetasikā → **mental** (as modifier); **mental factors** (as noun)
- vitakko → **initial application**
- vicāro → **sustained application**
- pīti → **zest**
- sukhaṃ → **happiness** (in jhāna context); **pleasure** (in sensory context)
- upekkhā → **equanimity**
- phasso → **contact**
- vedanā → **feeling**
- saññā → **perception**
- cetanā → **volition**
- samādhi → **concentration**
- paññā / ñāṇaṃ → **knowledge** (or **wisdom** where understanding is intended)
- saddhā → **faith**
- vīriyaṃ → **energy**

### Contested terms — mātikā specific
- katattā → **cultivated** (in kamma-resultant context: kamma that has been cultivated/performed and accumulated)
- appaṇihitaṃ → **desireless** (liberation aspect: free from desire/aspiration toward existence)
- apacayagāmiṃ → **leading to diminution** (diminution of accumulation; pair with "leading to accumulation" for upacayagāmiṃ)
- bahiddhā → **external** (not "externally" — adjective modifying phenomena, not adverb)
- chandādhipateyyaṃ → **predominance of desire** (desire as predominant factor)

## Structural conventions

- Preserve (Ka) / (Kha) / (Ga) section markers within blocks — do not remove or translate them
- Each block ID (`^block-id`) maps to exactly one output paragraph
- Heading levels (##, ###, ####) are preserved from the source
- Enumeration lists within a block are separated by line breaks where the source uses spacing, or by full stops where the source uses a period
- Do not add explanatory parentheticals unless the source contains them

## Prohibited choices

- Do not render dhammā as "things" or "factors" in enumeration context
- Do not render kusalā as "good" or "virtuous" — use "wholesome" consistently
- Do not render cetanā as "intention" — use "volition"
- Do not use "canker" or "influx" for āsava — use "taint"
