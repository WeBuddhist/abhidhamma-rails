# Translation

Language-by-language translations of the Abhidhamma produced from the rails. Each subfolder is a **brief-governed translation track**: one audience, one register, one locked terminology set.

## Subfolders

- `en-Contemporary-English-Abhidhamma/` — English, modelled on the NIV translation brief (optimal equivalence + reader-accessible English + committee review).

Add additional tracks alongside this one as they are commissioned (e.g. `bo-Classical-Tibetan-Abhidhamma/`, `zh-Modern-Mandarin-Abhidhamma/`, `en-Scholarly-Abhidhamma/`). Each track is one folder, contains `brief.md`, `terminology.md`, and `outputs/`, and follows the citation chain (`1-SOURCES/` → `2-RAILS/` → `3-TRANSFORMATIONS/`).
