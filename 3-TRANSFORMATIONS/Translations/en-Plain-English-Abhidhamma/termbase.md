# Termbase — en-Plain-English-Abhidhamma

The vocabulary contract for this track: **one chosen rendering per keyword**, locked once reviewed. Requirements say *how* we write; this file says *which words*; `audience.md` says *who we write for*.

## Provenance and status

This file was **scaffolded after the fact**. The translation `en-vibhanga-khandhavibhanga-plain.md` was produced against a termbase (`AI_translation/pali-english-termbase-plain.md`) that was never committed to the vault. The rows below were **harvested back out of the delivered translation** by counting actual usage — they record what the translation *does*, not a contract it was checked against.

Every row is therefore `harvested` rather than `complete`. A reviewer should confirm each one, and in particular decide where this track should agree with or deliberately diverge from the BB-curated renderings in `../en-Contemporary-English-Abhidhamma/termbase.md`.

**Known divergence from the Contemporary track:** none identified so far for the five aggregates — both render *khandha* as "aggregate", *saññā* as "perception", *cetanā* as "volition". The plain track's distinctive character is in sentence shape and connective tissue, not yet in terminology.
