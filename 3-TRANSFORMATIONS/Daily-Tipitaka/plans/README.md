# Plans

The 200 days are organised into **plans** — short arcs of a few days each, each covering one coherent unit of the Abhidhamma (a mātikā cluster, a chapter, a topic). A plan is the smallest committable rhythm. Practitioners can start the next plan even if they missed the last one.

## Files in this folder

- `plans-index.md` — the master index of all plans: plan-ID, day-range, title, the Abhidhamma material it walks through, and its status.
- `plan-001-<slug>.md`, `plan-002-<slug>.md`, … — one file per plan. Each plan file specifies:
  - Day range (e.g. `day-001 … day-005`)
  - The Abhidhamma passages each day covers (with rail references)
  - The arc — what the plan is trying to do, what the practitioner should come away with
  - A communication brief — the announcement copy that opens the plan, the notification copy that closes it

## Naming

- `plan-NNN-<slug>.md` — three-digit plan number, hyphenated slug describing the topic.
- Examples: `plan-001-orientation.md`, `plan-002-tika-matika-opening.md`, `plan-014-duka-matika-binding-clusters.md`.

## Working order

Build plan-by-plan, not day-by-day across all 200. Finish every language track for one plan, review, lock, then begin the next plan.
