# Assets

Supporting media for the Daily Tipitaka.

## Subfolders

- `liturgy/` — the fixed Pāli liturgy used in every day-file: `vandana.md`, `intention.md`, `aspiration.md`. Per-day files transclude these so the wording stays identical across all 200 days and all languages.
- `audio/` — chanting audio per plan and per announcer voice. File naming: `plan-NNN/day-NNN-<voice>.<ext>`.
- `images/` — banner art for announcements, plan-milestone graphics, social-media stills.
