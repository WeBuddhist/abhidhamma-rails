# Social Media

Posts for plan milestones, sample-day teasers, practitioner testimonials, and the run-up to Bodhgayā.

## File naming

- `YYYY-MM-DD-<slug>.md` — dated so the publishing order is visible at a glance.
- `template-plan-milestone.md`, `template-testimonial.md`, `template-sample-day.md` — reusable shapes.

## Voice

Sangha-like, photographic, slow. A still image of the practice — a candle, a hand-written word, an open page — paired with one sentence of meaning. Never quote-card-style. Never urgency-driven.
