# Communications

The outreach and care layer around the daily content. The journey is 200 days long; without warm, well-paced communications, the daily content alone is not enough to keep practitioners walking.

## Subfolders

- `announcements/` — long-form announcements: launch, mid-journey rallies, the run-up to Bodhgayā. One file per announcement, dated.
- `notifications/` — the daily push-notification copy. Short, warm, anchored to the day's passage. Filed by day number to match `../days/`.
- `social-media/` — posts for plan milestones, sample-day teasers, practitioner testimonials.

## Voice

Warm, unhurried, sangha-like. Never marketing copy. Never urgency-driven. Notifications open with an image of the daily practice (a chant, a sit, an offering) and close by inviting the practitioner in — not by pressuring them.

## Languages

Communications follow the same language tracks as `days/`. Each file in `announcements/` and `social-media/` ships in every language we publish; `notifications/` is shorter so it stays one file per day per language.
